# Martials Integrated Consulting (`tkmartials.com`)

Official production-grade web application for **Martials Integrated Consulting** (Management Resource & Technology Solutions).

Built on Next.js 14 (Static Export), Tailwind CSS, Lucide Icons, and Supabase Cloud Database with Zero-Load Free-Tier Architecture on Cloudflare Pages.

---

## 🌟 Core Verticals
- **Textile Raw Materials & Sourcing Desk** (Cotton Bales, Ring Spun & Combed Yarn, Synthetics, Blends)
- **General Insurance & Corporate Risk Advisory** (Marine Cargo ICC(A), Property, Engineering Projects)
- **Technology Products & Enterprise Utilities** (SME Sourcing ERP, Batch Tracking, WhatsApp Invoicing)
- **Student Education Advisory** (Global University Admissions, Visa Documentation)
- **HR Operations & Workforce Optimization** (People Operations, Compliance)
- **Direct B2B Growth & Commercial Sales** (Market Intelligence & Supplier Introductions)

---

## 🛠️ Architecture & Tech Stack
- **Framework**: Next.js 14 App Router (`output: 'export'`)
- **Styling**: Tailwind CSS & Vanilla CSS
- **Database & Storage**: Supabase (PostgreSQL + Real-time Sync + Cloud Storage CDN)
- **Deployment Target**: Cloudflare Pages / Static Assets ($0/month, unlimited bandwidth)
- **CMS**: In-Line Visual Admin CMS with PIN Authentication (`tkmartials@#&654321`)

---

## 🚀 Getting Started

### Local Development:
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Static Production Export:
```bash
npm run build
```
Generates 100% static output in `./out` folder.

### Deploy to Cloudflare Pages:
```bash
npx wrangler pages deploy ./out --project-name=tkmartials
```
